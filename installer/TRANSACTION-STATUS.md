Completed code paths under validation: protected administrator/System store creation; file/root/directory owner,DACL,SACL,timestamp capture (audit access unavailable => refusal); unsupported encrypted/compressed/sparse/offline/reparse/named-stream cases refused rather than lost; complete verified backups; per-component flushed, resumable, exact-set rollback retaining failed data; exact typed uninstall registration, existing registration security and shortcut rollback; prior service configuration preserved without rewriting and checked (only transaction-created services stopped/deleted); PATH compare-and-swap restoration; PID/start-time/SID installer ownership; dead-owner recovery before another install; nonzero Inno exit on post-copy health failure. Already-stopped/no-service cases validate the complete stored state and its backup with the unchanged CLI, rejecting fallback-to-v5 diagnostics; this is NOT proof of the old writer's latest memory being saved. Original-user config identity is required to match the active Explorer session; an unverifiable or different-account install refuses rather than touching the wrong profile.
