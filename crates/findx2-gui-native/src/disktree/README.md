Actual source modules copied: tree.rs, treemap.rs, filter.rs, classify.rs, scan_preview.rs; viewport.rs extracts View/LayoutTransition from app/state.rs. Original tests retained. Local adaptations: crate paths, mutex poison recovery; viewport uses CPU Rect instead of GPUI Size<Pixels>, transition methods exposed. FindX's flat model adapter supplies both logical/allocated/unknown values without weakening identity or allocation correctness. Renderer/scan adapters carry their own upstream attribution. No upstream deletion, MFT/full-volume fallback, SSH, or gpui-omarchy application is included. Existing gpui-kit 0.9.1 is retained.

## Integration and boundaries

- Production layout: usage_view.rs -> bounded native Scan adapter -> these actual Node/classify/layout modules -> one workspace_usage.rs Canvas. View and LayoutTransition are actually used by camera and drill/ascend; no per-tile div hitboxes remain.
- Scanner: usage_scan.rs uses FileIdExtdDirectoryInfo in production, a fixed <=4-worker Rayon pool and <=4096 queued scoped jobs. ID-only iterative overflow is bounded by the explicit entry limit and does not drop directories. This is a FindX-specific Windows walker with dispatch_fixed-inspired scheduling, NOT a claim to have copied upstream's whole scanner/MFT path. Whole 128-bit IDs are retained for scan-time dedup; ordinary entries avoid per-file opens. Sparse/compressed files use exact refinement, unknown allocation remains unknown, logical lengths never substitute for allocation. Reparse/cloud/offline and changed-volume/identity boundaries are skipped/refused. Accounting covers unnamed streams; ADS enumeration is not implemented.
- Repository: measured-allocation-only provider contract; no formal engine/index IPC used. Multi-root 128MiB/8-root memory budget and 128MiB/8-root compressed disk budget under FindX-native-dev/usage-cache-v1; UTF-16 basenames/parent indices, schema/policy/root volume+128-bit ID+creation-time validation, bounded parsing and atomic MoveFileEx replacement. Source/as-of/partial are retained. Cached data is always unvalidated/stale, never declared fresh from directory mtime. Ancestor coverage only includes observed nodes. Cancelled compression leaves the in-memory partial result and old snapshot intact.
- Exact-key scans share one job, cancellation and progress; explicit Refresh/F5 forces measurement, navigation only loads known cache. A canceled shared job affects all attached observers. No automatic MFT, USN, persistent full file-ID tree, or index-based logical sketch is implemented. The future logical sketch needs a separate typed payload/interface rather than being passed off as allocation by MeasuredUsageProvider.
- GPUI kit stays 0.9.1. Original workspace MSRV is not a claim for this native edition-2024/upstream-modern port; validated compiler is MZ rustc 1.99.1; upstream declares 1.97.
