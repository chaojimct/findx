# FindX 2.5.9 — 发版记录（本地验收）

Baseline: 2.5.8. Tauri WebView GUI 删除后的第一个原生-only 版本；无索引格式迁移。
GitHub Release 构件由 `release.yml` 在 tag `v2.5.9` 上的 CI 重建（仅 Windows）产生，
与本地验收包不是同一字节。

## 本地验收（2026-11-22 Asia/Shanghai，同一台 2.4.10 三卷生产机）

- 安装包 `FindX-2.5.9-setup.exe`（12169202 字节，`dist/` + 桌面各一份），
  `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`，**EXIT CODE 0**。
- 升级前 2.5.8 → 升级后 GUI/服务均为版本 2.5.9（文件版本资源）。
- 服务 `FindX2Search` RUNNING，`healthy=true`，`loading=false`，
  `entry_count=9803182`，`watch_error` 为空。
- 占用页：`D:\` 根第一页 7 子项 + `next` 延续（48KB/2KB 预算分页正常）；
  代际抖动下翻页存活（2.5.8 已验证 +9000 代际漂移）。
- 停止门：本次 Prepare 内对旧服务（2.5.8）优雅停止一次通过，
  未再出现“停止超时”（旧拓扑升级线程已带停机中止）。

## 本版包含（相对 2.5.8，均已在真机验收）

- 占用页全览 🏠：此电脑 → 磁盘 → 盘内顶层三层方格，
  面包屑 `🏠 › D:\ › …`，卷根滚轮缩小/↑ 回全览，首次进占用页默认全览。
- 面包屑资源管理器规则：箭头属于左边的屑，点开展示它的子级；
  切盘入口固定在 🏠 的箭头。
- 占用页分页只按 epoch 失效；翻页预算 3→6（仅真重建才需要）。
- 设置页全部实时生效，无保存/取消；主题风格默认蓝白（原“VS Code”改名）。
- 服务停机不再因 stat 批次未决而非零退出；legacy 拓扑升级线程响应停机中止。
- 删除 `gui/`（Tauri）；产品图标移至 `assets/icon.ico`；
  CI 的 mac/Linux Tauri 打包已下线（原生跨平台打包待定）。
