# FindX 2.5.11 发版记录（本地验收）

GitHub Release 构件由 `release.yml` 在 tag `v2.5.11` 上的 CI 重建（仅 Windows）产生；
本地验收结论（`release/2.5.11.json` 的门）：

相对 2.5.10 的变更集中在 GUI（`crates/findx2-gui-native`），另有一笔服务端 additive
状态字段（见门 1）。`v2.5.10..main` 共 23 个提交：设置搜索与深链接内核、详情面板三态、命令面板接线、
CSV 导出彻底移除、page-enter 动画与导航指示器、WAL 健康段/诊断包/已索引位置/
SHA256SUMS 校验、设置搜索内容+拼音、右键菜单按页面区分、鼠标标签操作与可自定义
快捷键、Explorer 式侧栏（收藏置顶 + 此电脑树）、文件/侧栏收藏与右键菜单、
目录标签不换行、更新器安装进度（P1+P2）。

## 门 1：engine-io-storm-fixed（P0，通过，沿用 2.5.10）

- 持久化路径零改动（`git diff v2.5.10..main` 对核心持久化文件为空）：
  对 `findx2-core` 为空；对 `findx2-service`/`findx2-ipc` 仅有一笔 additive 状态字段
  （`82ae8d4`，`#[serde(default)]` 兼容旧版，供 GUI 健康条用）。2.5.10 的 WAL+fold 结论继续有效。

## 门 2：wal-crash-recovery（P0，通过，沿用 2.5.10）

- 同上，崩溃恢复路径无改动；回归套件随门 3 重跑。

## 门 3：persist-test-suites（P0，重跑通过）

- `cargo test --workspace --exclude findx2-gui-native -- --test-threads=1` 串行通过；
- `cargo test -p findx2-gui-native --lib`：406 passed / 0 failed / 6 ignored
  （含新增：安装三阶段文案/卡片模型/确定性进度条/SILENT 参数全等/
  ShellExecuteExW 等待与退出码/版本翻转校验/源码扫描回归）；
- `cargo build -p findx2-gui-native` 成功。

## 门 4：fold-quiescence-in-prod（P0通过，沿用 2.5.10）

- fold 调度与阈值无改动。

## 门 5：legacy-2-4-multivolume-index-loads（P0通过，随全量套件）

- 随门 3 全量套件通过，无格式迁移。

## 未跑的门（P1/P2非阻塞，均在 json 中标 false）

- installer-live-handoff：本次在应用内更新链路有改动（/SILENT + 进程等待），
  但安装事务脚本（Prepare/Verify/Commit/回滚）一行未碰，回滚语义由
  exit-80 单测与源码扫描回归覆盖；安装包升级矩阵留待用户侧首轮验证。
  注意：本地从不用正式包做升级 round-trip（会替换已安装产品），
  与 Argus 一致只在虚拟机/用户侧验证。
- strict-protocol2-stop-receipt、macos-linux-native-packaging：延续 2.5.9 状态。
