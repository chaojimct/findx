# FindX 2.5.12 发版记录（本地候选）

GitHub Release 由 `release.yml` 在 tag `v2.5.12` 上的 CI 重建（Windows）。本地验证结论见 `release/2.5.12.json`。

相对 2.5.11 的改动分两块：GUI（窗口材质/预览/PDF/页签）与全文内容索引协议扩展（service/IPC/content， additive serde-default 字段 + ContentBuild/Cancel + `<index>.content/` 独立存储）。

## 门 1（engine-io-storm-fixed，P0）通过：相对 2.5.10

- 持久化路径无改动：`git diff v2.5.10..main` 以外的持久化文件为空；`findx2-core` 为空；`findx2-service`/`findx2-ipc` 只有 additive 状态字段（`#[serde(default)]` 兼容旧版）；content 索引是独立目录的新文件，不碰 index.bin/WAL。

## 门 2（wal-crash-recovery，P0）通过：相对 2.5.10

- 同上，崩溃恢复路径无改动。

## 门 3（persist-test-suites，P0）通过

- `cargo test --workspace --exclude findx2-gui-native -- --test-threads=1` 通过（含 content 全管线 + cancel）。
- GUI lib：413 passed / 2 failed / 6 ignored；2 个失败是暂停中的设置重构（服务页标识、更新安装流程断言），与本版改动无关，随该分支落定时修。
- `cargo build -p findx2-gui-native` 成功；`cargo check --workspace --all-targets` 零错误。

## 门 4（fold-quiescence-in-prod，P0）通过：相对 2.5.10

- fold 参数/阈值无改动。

## 门 5（legacy-2-4-multivolume-index-loads，P0）通过：继承 2.5.11 结论

- 无格式迁移。

## 本版 GUI 验证（用户目测 + 仪器）

- 窗口材质：DWM systembackdrop 生效（readback=ACRYLIC/MICA），backbuffer 像素 alpha 0.15~0.9 回读确认，插件白底已除；标题栏/侧栏透出壁纸。
- 预览：选中即显文件头 + loading/错误态；tab 条顶头。
- PDF：系统预览处理器优先（翻页原生），WinRT 光栅兜底；传输协议去 JSON 化 + 页缓存 + oneshot 等待。

## 未覆盖项（P1/P2，json 里标 false）

- installer-live-handoff：沿用 2.5.11 状态。
- strict-protocol2-stop-receipt、macos-linux-native-packaging：沿用 2.5.9 状态。
